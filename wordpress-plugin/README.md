# INAD Content Manager

WordPress plugin for the INAD promotional website. It provides:

- Project brand folders with cover and gallery images across BTL, Events,
  Branding, Print, Publication, and Product Launch Event categories
- Client logos
- About-section video selection
- Public read-only endpoint: `/wp-json/inad/v1/content`

## Install

In WordPress, open **Plugins → Add New Plugin → Upload Plugin**, upload
`inad-content-manager.zip`, and activate it. A new **INAD Content** menu then
appears in the WordPress dashboard.

Use **Projects → Add New** to add a project. Use the Cover Image panel for its
folder cover, and the Project Details box for its gallery. Every gallery card
uses the project's Campaign title; Media Library filenames are not displayed.

Use **Client Logos → Add New** to add a logo. Use the Logo Image panel for the
image.

Use **About Video** to select the homepage video.
